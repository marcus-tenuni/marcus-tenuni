## 🏛️ Featured Projects

### 1. Legal-AI-Analyzer
**Intelligent Contract Analysis Engine**

An AI-powered system that automatically analyzes legal documents using Natural Language Processing. It extracts key entities (parties, dates, amounts), classifies clauses, and identifies potential risks.

- **Tech Stack**: Python, FastAPI, SpaCy NLP
- **Key Features**: Entity extraction, clause classification, risk assessment
- **Repository**: [legal-ai-analyzer](https://github.com/marcus-tenuni/legal-ai-analyzer)
- **Status**: Production-Ready ✅

```python

  "clauses": {...},
  "risks": [...]
}
```

**Corporate Entity & Filing Management API**

- **Tech Stack**: Node.js, Express.js, TypeScript, Zod
- **Key Features**: Entity CRUD, director/shareholder tracking, filing management, type-safe validation

- **Status**: Production-Ready ✅

**API Endpoints**: 10+ RESTful endpoints for complete entity lifecycle management
